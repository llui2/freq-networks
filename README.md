# Frequency-resolved spectral distance

For the weighted combinatorial Laplacian $L=D-W$, with
$L\psi_k=\lambda_k\psi_k$, the frequency-resolved distance is

$$
d_{\Omega,\eta}(i,j)
=
\left[
\sum_{k=2}^{n}
\frac{\bigl(\psi_k(i)-\psi_k(j)\bigr)^2}
{(\lambda_k-\Omega)^2+\eta^2}
\right]^{1/2},
\qquad \eta>0.
$$
